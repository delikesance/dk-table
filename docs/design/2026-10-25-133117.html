Espion et analyse rapide

Deux idées absentes de dk-table (TODO, recherche axe 3). Écrans clair/sombre via le sélecteur de thème de la page Design.

1. Fenêtre Espion

Panneau flottant qui suit des cellules choisies, toutes feuilles confondues, avec leur valeur recalculée en direct. On modifie une feuille, on lit le résultat sur une autre sans changer d'onglet.

Interfaces et contrats

Types (src/ui/spy/types.ts)
  WatchItem  = { id: string; sheetId: string; key: string /* "B2" */ }
  WatchRow   = { item: WatchItem; label: string /* "Synthèse!B1" */; display: string;
                 raw: string; error: string | null; delta: number | null }
Fonctions pures (src/ui/spy/spy.ts)
  addWatch(items, sheetId, key): WatchItem[]        // dédoublonne, max 50
  removeWatch(items, id): WatchItem[]
  rowsOf(items, read: (sheetId,key)=>{display,raw,value}, prev: Map): WatchRow[]
  shiftWatch(items, op: StructOp): WatchItem[]       // suit insertion/suppression (structure.ts), supprimée -> #REF!
Câblage
  App.watch(): readonly WatchItem[]   App.addWatch(sel?) / App.removeWatch(id) / App.openSpy()
  Rafraîchi par appGrid.touch (même point que refreshCf), une seule passe par recalcul
  Persisté : DocSheet-niveau classeur `watch?: {sheet: string; key: string}[]` (io/watchFormat.ts, absent si vide, ancien format OK)
  Non annulable (comme volets figés). Clic ligne -> app.goto(sheetId,key)
Événements : "spy:open" | "spy:change" ({rows}) ; raccourci Alt+Maj+W ; menu Affichage > Fenêtre Espion ; palette view.spy
Fichiers : src/ui/spy/{spy.ts,panel.ts,spy.css}, src/io/watchFormat.ts, appSpy.ts, menubar/spec.ts (une entrée)
Tests à écrire d'abord (npm test)
  spy.test.ts : addWatch dédoublonne et plafonne à 50; rowsOf calcule delta; erreur -> error "#DIV/0!"; shiftWatch après insertion de ligne -> clé décalée; suppression -> #REF!
  watchFormat.test.ts : aller-retour, fichier sans `watch` accepté
  e2e/feat-spy.spec.ts : ajouter B2, éditer, valeur du panneau change sur l'autre feuille; captures clair/sombre

2. Analyse rapide (Ctrl+Q)

Sur une sélection de données, un badge en bas à droite ouvre un menu : totaux, graphiques en cellule, formats. Survol = aperçu dans la grille, clic = application en un pas d'annulation. Réutilise SOMME, SPARKLINE, BAR, TREND et le formatage conditionnel existants.

Interfaces et contrats

Types (src/ui/quick/types.ts)
  QuickTab   = "totals" | "charts" | "formats"
  QuickItem  = { id: string; tab: QuickTab; label: string; apply: Edit[]; preview: Edit[] }
  Edit       = { key: string; raw: string } | { cf: CfRule }       // même forme que app.batch / setCfRules
Fonctions pures (src/ui/quick/plan.ts)
  analyzeSelection(range: string, read: CellReader): { numericCols: number[]; numericRows: number[]; n: number } | null
      // null si < 2 valeurs numériques
  quickItems(a: Analysis, range: string, free: FreeCells): QuickItem[]
      // totals : SOMME/MOYENNE/NB/MIN/MAX sous (colonnes) ou à droite (lignes), cellules libres seulement
      // charts : SPARKLINE | BAR | TREND(plage de la ligne) dans la colonne libre à droite
      // formats: règles CF existantes (échelle de couleurs, barres, supérieur à la moyenne)
Câblage
  App.quickAnalysis(): QuickItem[]   App.applyQuick(id)  (un app.batch = un pas d'annulation)
  Aperçu : calque DOM éphémère (.dkg-qp), ne touche ni le moteur ni l'historique
  Badge : ui/quick/badge.ts, placé par floating.ts (placeFloating) au coin bas-droit de la plage, masqué si < 2 valeurs
Événements : "quick:open" | "quick:preview" ({id}) | "quick:apply" ({id}) ; Ctrl+Q ouvre, flèches naviguent, Entrée applique, Échap ferme
Fichiers : src/ui/quick/{plan.ts,panel.ts,badge.ts,quick.css}, appQuick.ts, commands.ts (raccourci), menubar/spec.ts (Édition > Analyse rapide)
Réutilise : ui/autosum.ts (logique de totaux), engine/live/adapter.ts, engine/cf/types.ts
Tests à écrire d'abord (npm test)
  plan.test.ts : analyzeSelection renvoie null sous 2 nombres; quickItems ne propose pas de cellule déjà occupée; totals pose SOMME sous chaque colonne; charts cible la colonne libre
  appQuick.test.ts : applyQuick = un seul pas d'annulation; preview n'écrit rien dans le moteur
  e2e/feat-quick.spec.ts : sélection, Ctrl+Q, survol (aperçu), Entrée; captures clair/sombre
