Interfaces et contrats

Espion

Types (engine/watch.ts, pur, sans DOM)
  WatchRef = { sheet: string; key: string }
  WatchRow = { ref; formula: string; value: string;
               prev: string|null; delta: number|null; error: boolean }
  watchRows(book, refs: WatchRef[], prev: Map): WatchRow[]
    delta = nombre courant - précédent, sinon null
    feuille/cellule supprimée -> error, value "#REF!"
Persistance : DktDoc.watch?: WatchRef[] (io/format.ts, validation stricte)
UI : ui/watch/panel.ts (fenêtre flottante, drag), ui/watch/watch.css
  createWatchPanel(app): { toggle(): void; add(ref): void; remove(ref): void }
Événements : app.on("recalc") -> panel.refresh() ; "watch:goto" {sheet,key}
Entrées : menu Affichage « Espion », menu contextuel « Espionner », palette view.watch
Fichiers : engine/watch.ts, io/format.ts, ui/watch/{panel.ts,watch.css},
  ui/menubar/spec.ts, ui/commands.ts (chacun reste <= 200 lignes)
Tests d'abord (vitest) :
  engine/watch.test.ts : delta chiffré, texte sans delta, #REF!, ordre conservé
  io/format.test.ts : aller-retour watch, refus d'une ref invalide
  ui/watch/panel.test.ts : refresh ne reconstruit que les lignes changées,
    clic ligne émet watch:goto, vide affiche le message
  e2e/feat-watch.spec.ts : modifier B1, la ligne Espion se met à jour

Validation

Types (engine/validate.ts, pur)
  Rule = { range: string;
    kind: "list"|"number"|"integer"|"date"|"length"|"custom";
    op?: "between"|"gt"|"lt"|"eq"; a?: string; b?: string;
    items?: string[]; mode: "reject"|"warn"|"mark"; message?: string }
  checkValue(rule, raw: string, lookup): { ok: boolean; reason?: string }
  invalidCells(sheet, rules): string[]   // clés marquées (collage inclus)
  ruleAt(rules, key): Rule | undefined
Persistance : DocSheet.validation?: Rule[] (io/format.ts), suit insert/suppr de
  lignes et colonnes comme engine/cf (structure.ts)
Annulation : un pas par modification de règle ; saisie refusée = aucun pas
UI : ui/validate/{dropdown.ts, tip.ts, dialog.ts, validate.css}
  openDropdown(cell, rule): choix -> app.setCell ; tip(cell, reason)
Événements : "cell:commit" passe par checkValue avant écriture ;
  mode reject = annule la saisie + info-bulle, warn = confirmer, mark = écrit
Rendu : coin orange + fond --err-bg (grille), chevron sur cellules liste
Fichiers : engine/validate.ts, io/format.ts, ui/validate/*, ui/grid/editor.ts,
  ui/cellview.ts, ui/menubar/spec.ts (menu Données), palette data.validate
Tests d'abord (vitest) :
  engine/validate.test.ts : list, between, entier, date, custom, plage ouverte
  io/format.test.ts : aller-retour, règle invalide refusée
  ui/validate/dropdown.test.ts : flèches + Entrée écrivent, Échap annule
  ui/grid/editor.validate.test.ts : reject bloque, warn demande, mark écrit
  e2e/feat-validate.spec.ts : liste, saisie hors liste, marqueur après collage
