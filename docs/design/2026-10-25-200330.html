Analyse what-if

Trois pistes non réalisées (recherche, axes 2 et 3) : Valeur cible, Scénarios vivants, Fenêtre Espion. Moteur pur, hors ligne, sans IA. Modèle de démonstration : prix, coût, volume, frais fixes, bénéfice.

1 — Valeur cible (Données > Valeur cible…)

Trouve l'entrée unique qui donne le résultat voulu. Réutilise solve.ts (Newton, repli bissection). Le mouvement montre la convergence : chaque itération réécrit l'entrée et recalcule le résultat.

2 — Scénarios vivants

Jeux nommés d'hypothèses sur les cellules d'entrée, stockés dans le .dktable. Un clic applique le jeu : les entrées changent, le recalcul se propage (flash). Colonnes de comparaison recalculées en direct, sans synthèse statique.

3 — Fenêtre Espion

Panneau qui suit des cellules (feuille, valeur, formule), même hors écran ou sur une autre feuille. Une valeur qui change clignote une fois. Clic sur une ligne = aller à la cellule.

type GoalSpec = { target: string; value: number; by: string; maxIter?: number /*100*/; tol?: number /*1e-9*/ };

  | { ok: true;  input: number; result: number; steps: GoalStep[] }
  | { ok: false; reason: 'not-formula' | 'not-numeric' | 'no-dependency' | 'no-convergence' | 'cycle'; steps: GoalStep[] };
goalSeek(sheet: Sheet, spec: GoalSpec): GoalResult   // solve.ts: Newton puis bissection; n'écrit pas dans la feuille
